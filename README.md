# Belia PBB

Mobile-first web shell for Parti Pesaka Bumiputera Bersatu Sarawak (PBB) members—news, Sayap Parti shortcuts, and bottom navigation. Installable as a progressive web app (`manifest.webmanifest`).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
